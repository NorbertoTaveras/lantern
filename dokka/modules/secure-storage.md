# Module mobilefoundation-secure-storage

DataStore-backed key-value and token storage contracts.

# Package com.norbertotaveras.mobilefoundation.securestorage

Defines storage keys, storage configuration, key-value storage, token storage, token types, token expiration helpers, and DataStore-backed implementations.

Apps should review the module documentation before storing highly sensitive data, because encryption support is separate from the current DataStore-backed foundation behavior.
